# License Exceptions

Written exceptions to `docs/LICENSE-POLICY.md`'s allowlist, granted by the
human maintainer only. `license-auditor` will not approve an out-of-policy
dependency on its own authority — see that agent's definition.

Empty at Phase 0. Format for future entries:

```
## <package>@<version>

- **License:** <SPDX>
- **Why it's needed:** ...
- **Why nothing on the allowlist works instead:** ...
- **Approved by:** <maintainer>, <date>
- **Scope of use:** <where in the codebase this is allowed to appear>
```
